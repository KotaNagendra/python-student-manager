# Python Student Manager

A structured Python project demonstrating core programming logic, Object-Oriented Programming (OOP) principles, and basic database integration using SQLite.

## Features
- **Student Data Management:** Filters and tracks student pass/fail performance.
- **Object-Oriented Programming (OOP):** Uses a `StudentRecord` class blueprint with instance attributes and methods.
- **SQLite Integration:** Creates a local database (`school.db`), inserts student records, and queries data seamlessly.

## Code Structure
- `student_manager.py`: Contains core logic, functions, OOP classes, and database handling.
